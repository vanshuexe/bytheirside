# ByTheirSide

A responsive Next.js website based on the supplied ByTheirSide PDF and Colour Book brand guide. Includes service tabs, plan selection, FAQ accordions, mobile navigation and an enquiry draft generator.

## Run locally

```sh
npm install
npm run dev
```

## Production

```sh
npm run build
```

The site is exported to `out/` for static hosting. No database or secrets are required.

## Contact configuration

The brief supplies no email address or WhatsApp number. The form therefore validates inputs and prepares an enquiry that visitors can copy or download. It does not send data or store personal information. Add a verified recipient or submission service before using the site to collect enquiries.

## Content and imagery

Plans, service descriptions, the founder story, trust statements and FAQ answers are adapted from the supplied brief. Placeholder testimonials have been omitted. The Colour Book informed the forest, sage, cream, sand and terracotta palette. Typography uses EB Garamond and DM Sans with local fallbacks.

`public/images/family-care.jpg` is an illustrative AI-generated photograph, produced with the built-in image generation tool. It does not depict actual providers or customers. It can be replaced with commissioned photography without changing the layout.
